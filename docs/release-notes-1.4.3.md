# AVACA 1.4.3

AVACA 1.4.3 adds source-backed scrape category selection so the collection can
be limited to the kinds of works selected by the user.

## Highlights

- Added multi-select filters for single, multiple, photo, retrospective, and
  VR works.
- Uses source-declared tags, genres, series, and labels; titles, work-code
  prefixes, and performer counts are not category predicates.
- Saves unresolved works for review instead of silently excluding them.
- Kept AV-Wiki as an optional work source and included its catalog tags in the
  category evidence pipeline.
- Preserved legacy scrape settings for compatibility without using them as new
  active filters.
