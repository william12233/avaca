# AVACA 1.6.2

## Highlights

- Frosted Glass now uses stronger blur and brighter edges across toolbars,
  cards, search fields, menus, dialogs, and controls.
- Frosted Glass has a fixed dark appearance. **Settings → Theme & Appearance**
  explains why the appearance options are disabled. Switching back to Default
  restores your saved appearance settings. Motion Effects remains independent.
- The software update dialog shows each status once. While downloading, the
  dialog displays the percentage, file sizes, and a progress bar.
