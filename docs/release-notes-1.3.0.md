# AVACA 1.3.0

AVACA 1.3.0 improves software updates, data transfer, and resource usage
while preserving the existing local collection workflow.

## Highlights

- Show live download percentage and downloaded/total bytes in the Settings
  page and update dialog.
- Stream update archives and file-backed data transfers to reduce peak memory
  use without changing archive formats or integrity checks.
- Centralize service lifecycles and bound image concurrency and cache sizes for
  more predictable system usage.
