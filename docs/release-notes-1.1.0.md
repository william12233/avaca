# AVACA 1.1.0

AVACA 1.1.0 adds a guided actress discovery workflow for finding and saving
actresses from the Minnano AV ranking instead of entering every actress
manually.

## Highlights

- Browse the current actress ranking from Minnano AV.
- Search the ranking and filter it by publisher.
- Select multiple actresses, skip already collected actresses, and import them
  with the configured actress detail source.
- Optionally queue work scraping for the selected actresses.
- Use the discovery flow in the localized English, Traditional Chinese,
  Simplified Chinese, and Japanese UI.
