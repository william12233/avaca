# AVACA 1.3.2

AVACA 1.3.2 refines the Settings experience into a consistent, responsive
control system that is easier to scan and maintain.

## Highlights

- Reorganize Settings into five focused categories for theme, interface,
  scraping, data management, and system/about actions.
- Standardize same-page controls to the shared 48px height and keep dynamic
  status or progress content separate from static option explanations.
- Replace always-visible explanatory copy with compact help indicators that
  open on mobile tap and desktop hover.
- Apply the app surface shape tokens to popup menus and dropdowns, and keep
  website connection testing copy concise.
