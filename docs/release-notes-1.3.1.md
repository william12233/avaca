# AVACA 1.3.1

AVACA 1.3.1 standardizes rounded surfaces across the responsive UI and makes
the visual rule reusable for future development.

## Highlights

- Align card, input, dialog, bottom-sheet, button, dropdown, and framed-image
  corners with their containing surface.
- Add shared shape tokens and a documented UI contract for new pages.
- Add regression coverage for alias dialogs and responsive detail controls.
