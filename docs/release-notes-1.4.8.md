# AVACA 1.4.8

AVACA 1.4.8 refines actress rating and Settings interactions.

## Highlights

- Rate each actress with discrete horizontal sliders, with clear unrated and
  save/cancel behavior.
- Keep the home sort sheet compact by grouping rating criteria in a collapsible
  section that shows the active criterion while closed.
- Open Scrape jobs directly from Settings and use equal-height collapsed
  headers for System and About.
