# AVACA 0.9.4

## 更新內容

- 統一 JavBus 與多來源刮削中的 `V`、`T`、`VT` 特典版後綴，讓特典版與一般版共用作品識別，並優先抓取一般版詳情頁。
- 為 `START`、`STARS` 作品加入已知的 DMM leading-one 圖片路由提示，也支援含數字的作品前綴。
- 擴充核准的 DMM 證據網址解析，支援 `pics.dmm.co.jp`、`pics` 與 `pics_dig` 形式，並安全正規化學習後的下載路由。
