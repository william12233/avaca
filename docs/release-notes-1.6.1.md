# AVACA 1.6.1

## Highlights

- Frosted Glass now blurs the content behind toolbars and settings panels.
  The page uses your selected palette's background, including AMOLED black
  when enabled.
- Open **Settings → Theme & Appearance** to expand the theme and appearance
  options separately. Compare both themes using the same empty collection grid.
- The **Motion Effects** switch shows a short collection-to-details preview.
  When motion is off or your system requests reduced motion, the preview
  shows two still frames.
