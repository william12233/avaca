# AVACA 1.0.1

AVACA 1.0.1 improves performance and reliability for large local collections
while preserving the 1.0.0 local collection product baseline.

## Highlights

- Faster gallery and Works queries with SQLite indexes and less repeated work.
- Lower image memory usage through size-aware local decoding.
- Lower peak memory usage during data export and Windows update extraction.
- More stable scrape progress persistence and a Flutter 3.44.8 CI baseline.
