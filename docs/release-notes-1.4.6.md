# AVACA 1.4.6

AVACA 1.4.6 makes the software update download progress visible and reliable
while retaining responsive update status notifications.

## Highlights

- Updated the download progress indicator as intermediate percentages arrive.
- Kept progress smooth for known download sizes and indeterminate for unknown
  sizes.
- Added coverage for streamed download progress and the update screen.
