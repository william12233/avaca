# AVACA 1.2.0

AVACA 1.2.0 replaces the single-source actress ranking prototype with a
source-native 女優榜 for discovering and collecting actresses.

## Highlights

- Browse native actress directories from Minnano AV, JavBus, and AvBase.
- Search actresses through Minnano AV, JavBus, AvBase, AV-Wiki, or JAVDB.
- Use source-native categories and pagination without artificial rank numbers
  or publisher filtering.
- Keep the existing AVACA card styling, duplicate detection, multi-select
  import, and optional work-scraping flow.
- Restore Minnano S1 discovery and handle unavailable JAVDB/Cloudflare
  responses without showing fake results.
