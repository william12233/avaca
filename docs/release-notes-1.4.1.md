# AVACA 1.4.1

AVACA 1.4.1 updates work storage records so the saved state is represented by
the selected storage types.

## Highlights

- Select any combination of cracked, original, and subtitle files for a work.
- Keep quality and frame rate as optional metadata, including 4K quality.
- Reset legacy saved storage flags during migration so the new storage choices
  start unselected and remain unambiguous.
